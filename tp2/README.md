# Kinesio.Saludd

Proyecto de Aplicaciones Web 2.

En esta etapa se incorpora un servidor web con Node.js y Express para servir el sitio y comenzar la integración con una API externa.

## Ejecución

1. Instalar dependencias con `pnpm install`.
2. Iniciar el servidor con `pnpm run dev`.
3. Abrir `http://localhost:3000` en el navegador.
